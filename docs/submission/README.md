# Документы заявки (Положение, п. 8)

| Требование | Файл |
|---|---|
| Резюме проекта RU + EN (≤ 1 стр.) и one-pager | `Qalqan_one-pager_RU.docx`, `Qalqan_one-pager_EN.docx` |
| Pitch-deck (10–12 слайдов), с заметками докладчика на 5–7 минут | `Qalqan_pitch-deck.pptx` |
| Техническое приложение (методика, данные, метрики, тест-кейсы, TRL) | `Qalqan_tech-appendix.docx` |
| Демо: видео до 5 минут | сценарий — `video_script.md`, приложение — `../../demo/` |

Перед подачей заполните: **[ФИО], [курс, образовательная программа]** во всех документах и
**[ссылка на видео]** на слайде 9; откройте репозиторий, если даёте на него ссылку.

Документы генерируются скриптами из `_build/` (Node.js: `npm install` в `_build`, затем
`node onepager.js <папка>`, `node deck.js <файл.pptx>`, `node appendix.js <файл.docx> <корень репозитория>`).
