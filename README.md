# Қалқан — инкрементальный детектор мошеннических звонков для казахстанского рынка

Система, которая оценивает риск **по ходу разговора**, а не после него, и поднимает
тревогу до того, как жертва выполнит целевое действие (продиктует SMS-код,
переведёт деньги на «безопасный счёт», установит программу удалённого доступа).

Рабочие языки: **казахский, русский и смешанная речь** (code-switching) —
то, как реально говорят в Казахстане.

## Проблема

По данным Антифрод-центра Национального Банка РК на 01.01.2026:

| Показатель | Значение |
|---|---|
| Инцидентов с признаками мошенничества | 80 871 |
| Заблокировано | 2,8 млрд ₸ |
| Возвращено пострадавшим | > 500 млн ₸ |
| Доля телефонного мошенничества | 22% |
| Доля фейковых инвестиций | 19% |

Существующий контур — **реактивный**: он разбирает инциденты после факта.
Превентивного контура, работающего во время звонка, в стране нет.

на казахском языке не существует.

## Таксономия (готово, v3.1)

**11 тем звонков — у каждой мошеннический и легитимный сценарий.** Тема
выбирается независимо от класса, приветствие берётся из общего пула темы:
детектор должен распознать приём манипуляции, а не тему звонка
(почему это важно — [карточка датасета](docs/dataset_card.md#история-артефакт-темы-в-v1)).

| Тема | Мошенничество | Легитимный звонок |
|---|---|---|
| Банк | SC01 служба безопасности → «безопасный счёт» | BN01 банк подтверждает операцию |
| Кредит | SC06 «одобренный кредит» + фишинговая ссылка | BN04 взыскание по реальной просрочке |
| Связь | SC02 продление договора на SIM → код из SMS | BN05 предложение тарифа |
| Безопасность номера | SC03 SMS-бомбинг + «Антиспам» (08.2026) | BN09 настоящее уведомление оператора |
| Пенсия | SC04 ЕНПФ: «неучтённый стаж» | BN10 информационный звонок ЕНПФ / ЦОН |
| Инвестиции | SC05 фейковые инвестиции (19% инцидентов) | BN07 лицензированный брокер |
| Техподдержка | SC07 удалённый доступ (AnyDesk, демонстрация экрана) | BN11 поддержка по заявке клиента |
| Родственник | SC08 ИИ-клонирование голоса | BN02 родственник действительно просит денег |
| Доставка | SC09 «курьер» просит код из SMS (07–08.2026) | BN03 настоящий курьер |
| Поликлиника | SC10 «номер медицинской декларации» = код DamuMed (Минздрав, 2026) | BN06 регистратура |
| Работа | SC11 вакансия-приманка: вербовка дропперов (АФМ, ст. 232-1 УК) | BN08 работодатель / HR |

Каждый мошеннический сценарий подтверждён открытым источником РК
(Генпрокуратура, Нацбанк, МВД, ЕНПФ, Минздрав, АФМ, полиция).

**7 стадий разговора** (S0 контакт → S6 извлечение) и **23 красных флага**
с весами — они же служат объяснением решения модели пользователю.

**Фразобанк v3.1:** 2 501 формулировка (1 410 русских, 1 091 казахская) в 364
пулах. Корпус переделывался трижды, каждый раз — из-за найденного признака, по
которому задачу можно было решить, не поняв приёма манипуляции: тема звонка (v1),
одни и те же формулировки в обучении и тесте (v2), вежливость и слово
«официальный» только у легитимных звонящих (v3). Подробности и проверки —
[карточка датасета](docs/dataset_card.md).

## Ключевая метрика

`turns_to_detection` — на какой реплике система впервые превысила порог.
Цель: срабатывание на стадии S3 (изоляция и давление), то есть **до** запроса
целевого действия на S5. Предупреждение, поступившее на S5, уже почти опоздало.
