# Қалқан — инкрементальный детектор мошеннических звонков (LoRA)

Адаптер к `xlm-roberta-base` для оценки риска телефонного мошенничества
**по ходу разговора**: после каждой реплики модель получает весь префикс
разговора и возвращает вероятность того, что звонок мошеннический.
Роли говорящих не используются — в расшифровке реального звонка их нет.

Это seed 42 из трёх обученных; корпус — Қалқан v3.1.

## Как использовать

```python
from peft import PeftModel
from transformers import AutoModelForSequenceClassification, AutoTokenizer

tok = AutoTokenizer.from_pretrained("FacebookAI/xlm-roberta-base")
base = AutoModelForSequenceClassification.from_pretrained("FacebookAI/xlm-roberta-base", num_labels=2)
model = PeftModel.from_pretrained(base, "models/v31/xlmr-lora-s42").eval()
```

Реплики склеиваются через `[SEP]` с обрезкой слева до 256 токенов
(`src/detector.py`, класс `PrefixEncoder`). Поверх вероятностей — накопитель
риска: EWMA с a = 0.5, порог 0.576 (выбран на валидации при FPR ≤ 5%);
параметры лежат в `qalqan_meta.json`. Готовый конвейер — `demo/app.py`.

## Обучение

| | |
|---|---|
| Данные | синтетический корпус Қалқан v3.1: 3 400 train + 600 val диалогов, 30 237 префиксов |
| Языки | русский, казахский, смешанная речь |
| LoRA | r = 16 на query/key/value + голова классификатора — 1,48 млн обучаемых параметров из 279,5 млн |
| Режим | 3 эпохи, lr 2·10⁻⁴, batch 32, fp16, Tesla T4 (Kaggle), 6,4 минуты |

## Качество

ROC AUC, среднее ± σ по трём сидам; правила — регулярные выражения по
красным флагам:

| Набор | Модель | Правила |
|---|---|---|
| шаблонный holdout (синтетика) | 0.805 ± 0.012 | 0.526 |
| реальный вишинг, Корея → ru | 0.799 ± 0.014 | 0.505 |
| реальные скам-звонки против звонков в банк, en → ru | 0.910 ± 0.011 | 0.505 |
| реальные скам-звонки против легитимных на ту же тему | 0.670 ± 0.014 | 0.505 |
| те же реальные звонки → казахский (KazLLM) | 0.789 ± 0.008 | 0.512 |

На holdout при пороге с валидации тревога звучит **до** запроса кода или
перевода в 85% мошеннических диалогов (правила — 36%).

## Ограничения

- Обучена только на синтетике; на реальных звонках хорошо **ранжирует**, но
  порог с синтетической валидации не переносится (FPR 0.41–0.68) — его нужно
  калибровать на данных конкретного банка.
- Казахская часть корпуса не вычитана носителем языка.
- Отрицание читает плохо: «если предложат установить AnyDesk — откажитесь» и
  «установите AnyDesk» для неё похожи.
- Качество в живом режиме ограничено распознаванием речи, особенно на
  казахском и на телефонном звуке.
- Клонированный голос родственника по тексту почти не отличается от настоящей
  просьбы: нужен акустический модуль.
